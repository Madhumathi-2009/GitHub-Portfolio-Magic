### About this repo
> My handwritten journey of building an aesthetic & professional GitHub portfolio - with ZERO coding!
> This repo is my learning diary - from seeing a friend's animated profile to creating my own cute lavender-themed portfolio!

---

### 📂 What's Inside?

> **📄 Dynamic-Typing-Notes.pdf** 
My research notes on how that typing magic works. How GitHub allows SVG and SVG has animation inside.

> **📄 Magic-Behind-my-cute-Portfolio.pdf**
My full implementation notes. All my colors, fonts, badge groupings and secret customizations.
